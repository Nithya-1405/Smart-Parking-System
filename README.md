The Smart Parking System is an embedded system project developed using an Arduino UNO, ultrasonic sensor, and servo motor. The system is designed to automatically detect an approaching vehicle and control the parking gate. The ultrasonic sensor measures the distance and detects the vehicle when it comes within a predefined range. The Arduino UNO processes the sensor signal and controls the servo motor. When a vehicle is detected, the servo motor rotates to open the parking gate and allows the vehicle to enter. After a few seconds, the servo motor returns to its original position and the gate closes automatically. This system helps reduce manual effort and improve parking efficiency. It is a simple, low-cost solution suitable for small-scale parking applications.
